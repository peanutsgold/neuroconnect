# NeuroConnect

A website that explains brain injury and related health problems in plain language — types of injury, symptoms and warning signs, an interactive brain map, recovery, a daily symptom tracker, and support resources.

Built with plain HTML, CSS, and JavaScript. No build step: open `index.html` in a browser.

## Pages

| Page | Contents |
|---|---|
| `index.html` | Home |
| `about.html` | What brain injury is, severity, and types |
| `brain-map.html` | Interactive brain map |
| `symptoms.html` | Symptoms and emergency warning signs |
| `health.html` | Related health problems |
| `recovery.html` | Recovery, everyday tips, FAQ |
| `tracker.html` | Daily symptom tracker (saved in the browser only) |
| `support.html` | Support organisations and helplines |

## Disclaimer

NeuroConnect provides general information only and is not a substitute for professional medical advice, diagnosis, or treatment.
